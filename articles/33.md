# S参数到底怎么看：怎样测准、怎么判断，出现深坑后如何定位

<div class="article-meta"><span class="badge">📘 模块三 · 信号完整性 SI · S 参数</span><span class="badge">⏱ 约 23 分钟</span><span class="badge qr">🔧 含工程师速查</span></div>


一条四端口差分通道完成VNA测量后，报告里出现两个异常：

- `Sdd21`在约6.4 GHz出现明显深坑；
- `Scd21`在同一频段升高。

工程师很容易马上下结论：

> 一定是板上的过孔残桩造成谐振，同时差分不平衡引起模式转换。

但这还不是证据。夹具谐振、端口配对错误、正负极性错误、校准漂移和不稳定的去嵌，都可能制造相似结果。

本文使用一条**25.78125 GBd NRZ四端口差分通道教学案例**贯穿全文。所有曲线均为合成模型，不代表真实DUT、接口限值或合规结果。我们要完成的不是背住S11和S21，而是一条工程闭环：

`定义测量对象 → 获得可信复数S参数 → 找到适用判据 → 区分DUT与台面 → 定位根因 → 对应整改 → 原条件复测`

读完本文，你应该能够：

1. 解释S参数为什么是带参考阻抗的**复数频率函数**；
2. 分清`S11(dB)`和正值Return Loss的符号；
3. 从四端口单端数据得到`Sdd11、Sdd21、Scd21、Sdc21`；
4. 正确区分校准、参考面移动和夹具去嵌；
5. 制定一套可复现的四端口VNA测量方案；
6. 判断一份Touchstone数据是否可信；
7. 在发现深坑或模式转换异常后，用受控A/B建立根因证据；
8. 找到规范或系统预算，并回到原条件完成复测。

## 一、S参数是什么：不是一条损耗曲线，而是一组复数行波关系

低频电路常用电压、电流和阻抗描述。频率升高后，互连具有明显传播延迟，端口上的入射波、反射波和透射波更适合描述网络行为。

对一个N端口网络，可以写成：

`b = S × a`

其中：

- `a`表示各端口的入射功率波；
- `b`表示各端口的出射功率波；
- `S`是散射矩阵。

在只激励端口`j`、其它端口都匹配时：

`Sij = 端口i的出射波 / 端口j的入射波`

因此二端口网络中：

- `S11`：端口1的反射；
- `S21`：从端口1到端口2的传输；
- `S22`：端口2的反射；
- `S12`：从端口2到端口1的传输。

![图1：四端口差分通道教学案例。Sdd21在6.4 GHz出现深坑，同时Scd21升高；这只是观察，尚不能直接宣布过孔残桩是根因。](/images/33/ill01_case_v2.png)

### S参数必须同时包含幅度和相位

S参数是复数：

`Sij(f) = |Sij(f)| × e^(jφij(f))`

仪器界面经常只显示幅度dB，但相位同样重要。群时延、脉冲响应、时域变换、眼图仿真和级联计算都需要完整复数数据。

例如：

`幅度(dB) = 20 × log10|Sij|`

`群时延 = − dφ / dω`

只有一张幅度截图，无法重新计算群时延，也无法可靠地进行时域定位、级联或去嵌。

![图2：同一S参数同时包含幅度和相位。只保存dB截图会丢失群时延、时域变换和级联分析所需的信息。](/images/33/ill02_complex_v2.png)

下面的动画演示VNA逐点扫频时，幅度和相位如何同时生成。相位斜率对应传播延迟；深坑附近的快速相位变化也是重要线索。

## 二、参考阻抗、端口和参考面都是结果的一部分

一条S参数曲线不能脱离三个条件解释：

1. **端口是谁**；
2. **参考阻抗是多少**；
3. **参考面在哪里**。

### 1. 参考阻抗

S参数中的入射波和反射波相对于端口参考阻抗定义。VNA常见单端参考阻抗为50 Ω，但这不是所有系统的物理常数。

差分混模分析常见：

- 每根单端线50 Ω；
- 差模参考阻抗100 Ω；
- 共模参考阻抗25 Ω。

具体数值必须以仪器设置和Touchstone文件中的`[Reference]`或选项行定义为准。

### 2. 端口映射

四端口差分通道至少要记录：

| VNA物理端口 | PCB网络 | 逻辑端 | 极性 |
|---|---|---|---|
| Port 1 | TX_P近端 | Pair 1 | + |
| Port 2 | TX_N近端 | Pair 1 | − |
| Port 3 | RX_P远端 | Pair 2 | + |
| Port 4 | RX_N远端 | Pair 2 | − |

交换同一差分对的正负极性，通常会让相关差模量相位翻转180°；把不属于同一对的端口错误配对，则可能直接制造假的模式转换和传输异常。

### 3. 参考面

测量参考面决定“曲线里包含了哪些结构”。参考面在VNA端口时，结果包含线缆和夹具；参考面移动到DUT入口后，才开始描述声明的DUT。

![图3：S参数的三个坐标条件。端口映射、参考阻抗和参考面任一项改变，结果含义都会改变。](/images/33/ill03_reference_v2.png)

> 一份报告如果没有端口映射、参考阻抗和参考面说明，就不能只凭曲线形状得出可靠结论。

## 三、从四端口单端数据到差分混模参数

真实差分通道通常由四个单端物理端口测量。VNA先获得完整的`4 × 4`单端复数S矩阵，再按端口配对转换成混模参数。

采用端口顺序`[1+, 1−, 2+, 2−]`时，常见参数包括：

| 参数 | 输入模式 → 输出模式 | 回答的问题 |
|---|---|---|
| `Sdd11` | 差模 → 差模反射 | 差分输入匹配怎样 |
| `Sdd21` | 差模 → 差模传输 | 有用差分信号传过去多少 |
| `Scd21` | 差模 → 共模传输 | 差分输入有多少变成共模 |
| `Sdc21` | 共模 → 差模传输 | 共模输入有多少转成差模 |
| `Scc21` | 共模 → 共模传输 | 共模能量怎样传播 |

首字母表示**输出模式**，第二个字母表示**输入模式**。因此：

- `Scd21`是差模输入、共模输出；
- `Sdc21`是共模输入、差模输出。

这两个名称不能颠倒。

混模转换还必须匹配仪器采用的波定义和参考阻抗。对等实数参考阻抗的功率波，常用归一化形式为：

`a_d = (a+ − a−) / √2`

`a_c = (a+ + a−) / √2`

这不是直接把导体电压做简单加减。若讨论电压，差模电压和共模电压还应按对应电压定义解释。

![图4：四端口单端数据转换成混模S参数。端口配对和极性必须先正确，才能解释Sdd21和Scd21。](/images/33/ill04_mixedmode_v2.png)

模式转换升高说明差分结构存在不平衡，但它仍然不是唯一根因证明。可能的候选包括：

- P/N线长度或损耗不一致；
- 过孔、焊盘或反焊盘不对称；
- 连接器pin field不对称；
- 参考平面或回流路径不连续；
- 端口配对、线缆相位或去嵌模型错误。

## 四、应该看哪些观察量

不同S参数回答不同问题，不能只盯`S21`。

| 观察量 | 常用显示 | 主要用途 | 不能单独证明 |
|---|---|---|---|
| `Sdd21` | 插入损耗、相位、群时延 | 差分传输、损耗、纹波和谐振 | 唯一物理根因 |
| `Sdd11/Sdd22` | 反射幅度与相位 | 两端匹配和反射频段 | 不连续点准确位置 |
| NEXT/FEXT | 串扰传输参数 | 邻对耦合 | 干扰发生的唯一位置 |
| `Scd21/Sdc21` | 模式转换 | 差分不平衡和共模风险 | 一定是长度不等 |
| 时域变换 | TDR/TDT或脉冲响应 | 延迟位置和局部反射候选 | 无带宽限制的精确物理位置 |
| 群时延 | 相位对频率的斜率 | 色散和延迟起伏 | 直接等于BER |

![图5：Sdd21、Sdd11、串扰、Scd21、相位和时域结果各自回答不同问题。](/images/33/ill05_observables_v2.png)

### S11(dB)和Return Loss的符号

两个写法经常被混用：

`S11(dB) = 20 × log10|S11|`

无源器件的`S11(dB)`通常为负值，越负表示反射越小。

`Return Loss = −20 × log10|S11| = −S11(dB)`

Return Loss通常写成正值，越大越好。

因此以下两句话含义相同：

- `S11 = −15 dB`；
- `Return Loss = 15 dB`。

报告必须明确采用哪一种表示法。

### 不要使用“通用−3 dB通道带宽”

均匀传输线的材料损耗基线通常随频率增加，但完整通道还会出现纹波和谐振深坑。高速串行通道的合规判定通常覆盖完整规定频段，并可能使用插损模板、拟合损耗、ILD、COM或其它派生指标。

`Sdd21`掉到−3 dB的位置可以描述某个特定网络的幅频点，但不能作为所有高速通道的通用合格判据。

## 五、什么时候需要测S参数

S参数主要用于描述线性网络和互连的频域行为。

常见场景包括：

- 高速串行通道的PCB、连接器、线缆和背板；
- 差分通道插入损耗、反射、串扰和模式转换；
- 封装、过孔、连接器和测试夹具建模；
- 频域到时域转换、通道级联和眼图/COM仿真；
- 无源滤波器、天线、匹配网络和RF器件。

以下情况不应只靠S参数：

- 有源Tx/Rx的实际摆幅、抖动、均衡训练和非线性行为；
- 长时间偶发误码和协议状态问题；
- 电源完整性中的大信号瞬态；
- I2C、SPI、UART等低速接口，通常先看电平、setup/hold和协议时序。

### 奈奎斯特频率按符号率计算

`Nyquist Frequency = Symbol Rate / 2`

- 25.78125 GBd NRZ：奈奎斯特频率约12.89 GHz；
- 112 Gb/s PAM4：符号率为56 GBd，奈奎斯特频率为28 GHz。

PAM4不能把112 Gb/s直接除以2得到56 GHz作为奈奎斯特频率。

![图6：什么时候使用S参数，以及NRZ和PAM4的奈奎斯特频率都应从符号率计算。](/images/33/ill06_when_v2.png)

奈奎斯特频率是重要观察点，但正式判定仍应覆盖规范规定的完整频段，不能只看一个频点。

## 六、S参数不能超过多少：标准和设计目标从哪里来

不存在脱离接口、代际、通道定义、参考面和频段的通用S参数限值。

查判据时按照下面的顺序：

1. 确认接口、代际、速率、调制方式和产品形态；
2. 确认DUT是芯片封装、主板、背板、连接器、线缆还是完整channel；
3. 确认测试点、参考面、端口阻抗和是否去嵌；
4. 查Base/PHY规范、channel specification、CTS或系统预算；
5. 确认参数名称、频率范围、拟合、积分或派生算法；
6. 在报告中记录标准版本、章节、表格和软件实现。

### 一个公开真实例子：IEEE P802.3bj

IEEE P802.3bj公开项目目标文件给出了100GBASE-KR4背板通道目标：

- 四条PCB电气背板lane；
- 每lane为25.78125 GBd NRZ；
- 奈奎斯特频率约12.9 GHz；
- 总channel insertion loss目标为：**12.9 GHz处不超过35 dB**。

这个数值用于说明真实工程判据必须绑定接口、速率、通道定义和频点。它不是所有25 GBd通道的通用限值，也不能直接拿来判定本文教学DUT。

![图7：判据查找路径，以及IEEE P802.3bj公开项目目标中“12.9 GHz处通道插损不超过35 dB”的真实示例。](/images/33/ill07_standard_v2.png)

基础设计阶段如果没有适用的接口规范，应建立系统预算，至少包含：

`Tx能力 + 通道损耗/反射/串扰 + Rx均衡与容限 + PVT/制造/连接器老化余量`

预算不是随意选择一个“常见−15 dB回损”或“−3 dB带宽”代替。

## 七、怎样正确测量四端口差分通道

### 第一步：定义DUT

写清：

- 通道起点和终点；
- 包含哪些PCB、过孔、连接器和线缆；
- 哪些结构属于夹具；
- 端口映射和正负极性；
- 目标参考阻抗；
- 原始结果和去嵌结果分别代表什么。

### 第二步：选择频率范围和网格

覆盖规范规定频段，并为时域分析保留足够带宽。使用等间隔频率点时：

- 时域分辨率近似受总带宽限制：`Δt ≈ 1 / B`；
- 无混叠时间范围近似受频率步进限制：`Tmax ≈ 1 / Δf`。

点数不能只为“曲线看起来平滑”设置，还要覆盖需要定位的传播延迟范围。

### 第三步：设置VNA

记录：

- 仪器型号和选件；
- 起止频率、点数和扫频方式；
- 端口功率；
- IF带宽；
- 平均次数；
- 接收机动态范围；
- 连接器类型、扭矩和线缆状态；
- 环境温度和校准时间。

功率、IF带宽和平均次数没有通用固定值。应通过功率A/B排除压缩，通过IFBW和平均A/B确认深坑及`Scd21`高于噪声底。

### 第四步：完成四端口校准

根据连接形式选择SOLT、TRL或其它适用校准方法，将校准参考面建立在声明位置。

校准后应使用**未参与校准的独立verification artifact**检查结果，不能只用原校准件证明自己正确。

### 第五步：测量并保存原始数据

先保存完整的`4 × 4`单端复数Touchstone数据，再进行混模转换和去嵌。

建议保留：

- 原始未去嵌`.s4p`；
- 去嵌后的`.s4p`；
- mixed-mode结果；
- VNA state文件；
- 端口映射照片；
- 校准和verification记录；
- 夹具模型及版本。

### 第六步：进行混模转换

确认端口顺序、配对和极性，再计算`Sdd、Sdc、Scd、Scc`。不要先看到模式转换异常，再倒推端口应该怎样配。

![图8：四端口差分通道VNA台面。端口编号、参考面、连接器扭矩、校准和原始s4p文件都必须可追溯。](/images/33/ill08_bench_v2.png)

## 八、校准、参考面移动和去嵌不是一回事

### 1. 校准

SOLT或TRL使用已知标准求解VNA系统误差，并在标准连接位置建立校准参考面。

### 2. Reference-plane extension

参考面延伸使用已知传播延迟或传输线模型，把已校准结果移动一段电长度。它不能自动消除任意复杂夹具。

### 3. 去嵌

如果校准面与DUT之间仍有夹具，需要测量或建模夹具网络，再通过网络级联反演移除夹具。

去嵌不是“把两条dB曲线相减”。它使用完整复数矩阵，因此会同时处理幅度、相位、反射和多端口耦合。

![图9：校准建立误差模型，参考面延伸移动已知电长度，去嵌数学移除复杂夹具；三者不能混为一谈。](/images/33/ill09_cal_deembed_v2.png)

### 去嵌结果怎样验证

至少执行：

1. 把去嵌后的DUT与夹具模型重新级联，检查能否回到原始测量；
2. 使用第二套夹具、不同长度线或2x-thru做A/B；
3. 检查无源性、因果性和互易性；
4. 比较去嵌前后噪声底和高频稳定性；
5. 保存夹具模型、算法和软件版本。

在端口采用实数正值参考阻抗并完成功率归一化的常见条件下，如果去嵌后的完整S矩阵最大奇异值明显大于1，或透射曲线出现无法由测量不确定度解释的正dB，应先怀疑夹具反演放大噪声、模型不准、校准残差或端口/阻抗错误，而不是宣布无源DUT产生了增益。

## 九、怎样判断一份S参数数据是否可信

正式对照规范前，先做数据质量检查。

| 检查项 | 观察方法 | 异常可能说明 |
|---|---|---|
| 重复性 | 重复连接、弯折线缆、重新扭矩 | 连接器或台面不稳定 |
| 噪声底 | 改IFBW和平均次数 | 深坑或串扰接近接收机底噪 |
| 功率线性 | 改端口功率 | 压缩、非线性或接触问题 |
| 互易性 | 对预期互易的DUT，在相同参考阻抗和端口定义下比较`Sij`与`Sji` | 端口/参考面不同、非互易结构或测量异常 |
| 被动性 | 对实数正值参考阻抗的功率归一化矩阵检查最大奇异值是否超过1 | 去嵌、模型、参考阻抗或数据异常 |
| 因果性 | 结合带宽、DC外推和窗函数检查负时间响应，必要时使用严格因果性算法 | 有限带宽处理或模型问题 |
| 重新级联 | DUT与夹具模型重新组合 | 去嵌流程是否自洽 |
| 端口映射 | 核对网络和极性 | 假模式转换或相位翻转 |

![图10：S参数数据可信度检查。先验证重复性、噪声底、端口映射、被动性、因果性和去嵌回代，再讨论DUT根因。](/images/33/ill10_quality_v2.png)

Touchstone文件至少应明确：

`频率单位｜S参数格式RI/MA/DB｜参考阻抗｜端口顺序｜mixed-mode顺序｜校准面｜去嵌状态`

Touchstone 1.x的选项行例如：

`# GHz S RI R 50`

表示频率单位GHz、网络参数为S、使用实部/虚部格式、所有端口默认参考阻抗50 Ω。它不能声明差分配对。

Touchstone 2.0可以进一步显式记录逐端口参考阻抗和混模顺序。下面只是两对差分端口的格式示意，具体阻抗必须与导出软件和波定义一致：

```text
[Version] 2.0
# GHz S RI R 50
[Number of Ports] 4
[Reference] 50 50 50 50
[Mixed-Mode Order] D1,2 D3,4 C1,2 C3,4
```

这里的`[Reference]`仍填写四个原始单端端口的50 Ω参考阻抗；100 Ω差模和25 Ω共模参考由混模关系派生。校准面、去嵌状态、夹具模型版本和端口物理网络通常还需要写入文件注释或伴随元数据。只看到`.s4p`扩展名，不能自动知道差分端口怎样配对，也不能知道数据是否去嵌。

## 十、案例：6.4 GHz深坑和模式转换升高怎样定位

回到开头的教学案例。

### 第一步：只写观察

- `Sdd21`在6.4 GHz出现深坑；
- `Scd21`在相同频段升高；
- 其它频段的材料损耗基线相对平滑。

这一步不能写“过孔stub导致Fail”。

### 第二步：先排除测量链

1. 核对四端口网络和极性；
2. 查看未去嵌原始`s4p`；
3. 更换线缆、重新连接和扭矩；
4. 使用第二套夹具；
5. 调整IFBW和平均，确认异常高于噪声底；
6. 把去嵌结果重新级联回原测量。

如果异常随夹具或去嵌模型移动，先修测量链。

### 第三步：获得延迟位置线索

对单端反射和`Sdd11`进行时域变换，使用声明的窗函数和传播速度估算反射延迟位置：

`距离 ≈ 传播速度 × 往返时间 / 2`

时域峰值只能给出有限分辨率的候选位置，不能仅凭一个峰值就宣布是某个过孔。

### 第四步：建立stub假设

开路stub的一阶四分之一波近似为：

`f_notch ≈ c / (4 × L_phys,eff × √ε_eff)`

其中`L_phys,eff`是包含边缘场和结构修正的等效物理长度，并不是已经包含介质传播效应的“电长度”。如果6.4 GHz深坑确实来自该模式的开路stub，缩短这段等效物理长度后，深坑频率应上移。

### 第五步：做受控A/B

保持板材、校准、端口映射、频率网格和去嵌方法不变，只改变可疑过孔残桩，例如增加背钻深度。

强证据应同时包括：

- `Sdd21`深坑向高频移动或减弱；
- `Scd21`同步改善；
- 时域反射候选减小；
- 原系统眼图或BER同步改善；
- 恢复原结构后问题能够复现。

![图11：从6.4 GHz深坑到过孔stub候选的证据链。先排除夹具和去嵌，再用时域位置、受控背钻A/B和系统结果共同证明。](/images/33/ill11_debug_v2.png)

## 十一、定位根因后怎样整改和复测

| 根因方向 | 常见整改 | 必须复查 |
|---|---|---|
| 过孔残桩 | 背钻、调整层转换、优化过孔结构 | 制造公差、反焊盘、其它lane |
| 差分不平衡 | 对称过孔/焊盘、减少P/N路径差异 | `Scd21/Sdc21`和EMI |
| 阻抗不连续 | 优化叠层、线宽间距、连接器launch | 两端反射和TDR |
| 材料损耗 | 缩短路径、选择适用低损耗材料 | 成本、加工和PVT |
| 串扰 | 增距、缩短并行、改善参考平面 | 其它victim和模式转换 |
| 测量台面 | 重做校准、修正端口、夹具和去嵌 | verification和重复连接 |

整改后必须恢复原来的：

`DUT定义｜端口映射｜参考面｜频率网格｜功率｜IFBW｜平均｜校准方法｜去嵌模型｜环境`

然后重新比较：

1. 原始未去嵌单端S参数；
2. 去嵌后的`Sdd21/Sdd11/Scd21`；
3. 时域反射位置；
4. 规范或设计预算余量；
5. 眼图、BER、EMI和其它系统指标；
6. 最差lane、温度、批次和连接器状态。

![图12：整改与复测闭环。根因对应整改后，必须在原条件下比较复数S参数、时域证据和系统结果。](/images/33/ill12_retest_v2.png)

问题消失不等于闭环完成。只有当改善能够被已验证的根因整改解释，并且没有破坏其它指标，结论才成立。

## 十二、🔧 工程师速查

### 1. 核心定义

| 项目 | 速查 |
|---|---|
| S参数 | 带参考阻抗定义的复数频率函数：`b = S × a` |
| Sij | 端口j激励，端口i响应 |
| 幅度 | `20log10|Sij|` |
| 相位/群时延 | 时域、级联、去嵌和色散分析不可缺少 |
| S11(dB) | 通常为负，越负反射越小 |
| Return Loss | `−S11(dB)`，通常为正，越大越好 |

### 2. 差分混模

| 参数 | 含义 |
|---|---|
| Sdd21 | 差模输入到差模输出 |
| Sdd11 | 差模输入反射 |
| Scd21 | 差模输入到共模输出 |
| Sdc21 | 共模输入到差模输出 |

### 3. 测量必填

`DUT边界｜端口映射/极性｜参考阻抗｜校准面｜频段/点数｜功率｜IFBW｜平均｜连接器扭矩｜校准方法｜verification｜去嵌模型｜Touchstone格式｜环境`

### 4. 数据可信度

`重复连接 → 改IFBW/平均 → 改功率 → 核对端口 → 比较互易性 → 检查被动/因果 → 去嵌重新级联`

### 5. 标准查找

`接口/代际/调制 → DUT和channel定义 → 参考面/阻抗 → 参数和频段 → Base/PHY/channel spec → CTS/算法 → 报告记录版本章节`

### 6. Fail闭环

`只写观察 → 排除台面 → 时域位置线索 → 建立物理假设 → 单变量A/B → 根因对应整改 → 原条件复测`
