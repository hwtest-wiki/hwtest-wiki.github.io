# 输出端调了一遍还是会复位，问题为什么在输入端？

<div class="article-meta"><span class="badge">📘 模块二 · 电源完整性 PI · 深化篇 · 输入电源完整性</span><span class="badge">⏱ 约 32 分钟</span><span class="badge qr">🔧 含工程师速查</span></div>


一块90 W平台，在实验室台式电源、30 cm粗线条件下连续满载没有问题。VOUT纹波、负载瞬态、环路响应和温升都在项目范围内。

换成产品适配器和1.5 m线束后，系统每隔几十毫秒复位一次。工程师先后增加输出电容、调整补偿、放宽PGOOD去抖，现象都没有消失。

真正有用的波形不是RESET下降后的那一段，而是它之前的200 µs：

```text
适配器输出端：完成12.0 V→10.8 V阶跃后保持稳定
滤波器前VIN：只有正常路径压降
转换器VIN引脚：先出现约10 kHz振铃，下降穿过折算后的8.5 V UVLO阈值
转换器VIN引脚：随后到达8.2 V最低点
内部UVLO：经过合成去抖/传播延时后确认
Switch node：确认后停止开关
VOUT：再开始下降
PGOOD：经过内部去抖后失效
RESET：最后才断言
```

屏幕上最后发生的是RESET，但第一错误不是RESET，也不是VOUT，而是**滤波器之后、转换器引脚处的VIN先越过UVLO**。

本文的电压、功率和阻抗来自**可复算的合成教学模型**；时间线是把阈值、去抖和延时显式列出的合成判读示例，并非电路方程仿真结果。它们都不代表任何具体适配器、CPU、GPU或DC-DC规格。真实项目必须回到Exact-model Datasheet、平台设计指南、适配器模型和项目批准的测试条件。

## 一、先划清边界：Load Transient与Line Transient改变的不是同一个量

两个测试都会看到VOUT变化，但激励源不同。

|项目|Load Transient|Line Transient|
|-|-|-|
|主动施加|输出负载电流Iout|上游输入源或规定输入参考面的电压阶跃|
|通常保持|输入条件|输出负载与系统状态|
|主要回答|负载突然取电时，输出电容与控制环能否接住|输入变化时，转换器、输入路径和保护能否保持工作|
|常见风险|下冲、过冲、恢复、输出环路振铃|输入过冲/下冲、输入LC振铃、UVLO、最小导通时间、源限流|
|必须实测|Iout、Vout、负载触发|DUT引脚Vin的实际幅值、边沿、振铃和越限，以及Iin、Vout、UVLO/PGOOD|

第13篇的负载阶跃是“负载从轻载跳到重载”。本篇的Line Transient是“负载状态明确时，输入电压从一个工作点变化到另一个工作点”。

现实系统里两者可能同时发生：CPU进入高功耗状态，适配器和线束压降增大，转换器为了维持输出又进一步增加输入电流。因此调试时要区分：

- **测试施加了什么激励；**
- **系统随后产生了什么响应。**

Line transient通过，只能证明规定输入阶跃、负载、温度、线束和滤波配置下的时间域结果。它不能自动证明全频段小信号稳定，也不能证明换任意适配器、LISN或线束都不会出问题。[1][2]

![图2：Load Transient与Line Transient边界。前者主动改变输出负载电流，后者向上游输入参考面施加电压阶跃并实测DUT VIN响应；两者都可能看到VOUT变化，但不能互相代替](/images/pi02/ill02_load_vs_line.png)

## 二、什么时候必须关注输入端，而不是继续调输出端

出现以下现象时，输入端应进入第一批测点：

1. 台式电源短线正常，产品适配器、长线束或LISN条件下复位；
2. 轻载正常，满载、Turbo、GPU/CPU同时工作时异常；
3. 标称输入正常，低线或电池低电量时异常；
4. 增加输出电容或修改补偿只能改变现象，不能消除首错；
5. VOUT下降之前，转换器VIN、EN/UVLO或switch node已经异常；
6. 进入EMI实验室后出现台架上没有的周期性振荡；
7. 适配器限流、hiccup或保护重启与系统复位同步；
8. 更换线缆长度、连接器或输入滤波器后，振荡频率或复位周期明显变化。

这些特征共同指向一个问题：转换器前面的网络不能再被当成理想电压源。

## 三、适配器不是理想12 V：源阻抗到底从哪里来

`Zs(f)`是从DUT输入参考面向上游看、将独立源小信号置零后得到的完整驱动点输出阻抗。它由电源输出网络、线缆、连接器、LISN和滤波器共同决定，通常必须按实际拓扑进行网络化简或直接测量。

```text
Zs(f) = driving-point output impedance seen from the DUT input reference plane
```

只有当某些元素在目标接口上确实可等效为串联阻抗时，才可以局部相加；含并联支路的LC或π型滤波器不能被当成一个与负载无关的串联标量。[3][4][6]

### 1. 适配器或台式电源

它有自己的反馈环、输出电容、ESR/ESL、Remote Sense、限流和hiccup。低频时控制环可能把输出阻抗压得很低；频率升高后，控制环退出，输出电容和寄生占主导；进入限流后，它已经不再是小信号线性源。

### 2. 线缆与连接器

电阻造成稳态压降和发热，电感在快速`di/dt`下产生瞬态压降，并可能与输入电容形成谐振。Remote Sense可以改善DC或低频电阻压降，但不能消除线缆的物理电感。

### 3. LISN、线束与EMI滤波器

它们不是透明附件。加入一个共模扼流圈、差模电感或LISN，就等于改变了DUT看到的频率相关源阻抗。NASA公开案例曾出现同一硬件在一个EMI设施异常、在另一个设施正常，根因正是设施源阻抗与DUT输入阻抗的交互不同。[9]

### 4. 输入电容

本合成案例假设标称47 µF的MLCC在直流偏压、温度和容差作用后有效值为22 µF。这不是47 µF MLCC的通用降额比例；真实值必须查Exact-model曲线或实测。输入电容既承担高频开关电流，也会与线缆或滤波电感构成谐振。只看BOM标称值，会把谐振频率和阻抗峰估错。

所以报告不能只写“输入12 V”。至少要写清：

- 电源或适配器型号、固件、限流和Remote Sense设置；
- 线缆长度、线径、连接器和转接板；
- 是否串接LISN、电流探头、分流器或临时电流环；
- 输入滤波器实装L/C/R和输入电容有效值；
- 测量参考面是电源端、连接器端还是转换器VIN引脚。

## 四、恒功率负载为什么会表现为负增量输入阻抗

先看本篇教学平台：

```text
Pout = 90 W
η = 90%
Pin = Pout / η = 100 W
```

当控制环仍能维持输出功率近似不变时：

```text
Iin = Pin / Vin
```

输入电压降低，为了维持同样的输出功率，输入电流反而上升：

|DUT VIN|IIN|
|-:|-:|
|12.0 V|8.333 A|
|10.8 V|9.259 A|
|9.6 V|10.417 A|

这就是“负增量”最直观的含义：电压往下动，电流往上动。

对工作点做小信号线性化：

```text
dIin/dVin = -Pin / Vin²
```

但这里的单位是S，所以它叫**负增量电导**，不是负输入电阻。负增量输入电阻应写成：

```text
rin = dVin/dIin = -Vin² / Pin
```

|DUT VIN|静态输入电阻`Vin/Iin`|增量输入电阻`dVin/dIin`|
|-:|-:|-:|
|12.0 V|+1.4400 Ω|−1.4400 Ω|
|10.8 V|+1.1664 Ω|−1.1664 Ω|
|9.6 V|+0.9216 Ω|−0.9216 Ω|

必须同时记住三个边界：

1. 静态电阻仍是正值，不能拿万用表测出“−1.44 Ω”；
2. 负增量模型只适用于工作点附近的小扰动；
3. 只有在控制环仍能维持调节的频段内，它才近似成立。

超过控制有效频段后，输入电容、功率级和控制器动态会接管输入阻抗；一旦越过UVLO、限流、OVP或hiccup，小信号负阻抗模型也不再适用。[3][7][8]

低线、满载通常更危险，因为`|rin|=Vin²/Pin`随Vin降低、Pin升高而变小，更容易接近输入源阻抗峰值。

![图4：90 W输出、90%效率的恒功率教学模型。Vin从12.0 V降到9.6 V时Iin从8.333 A升到10.417 A；静态V/I为正，dI/dV是负增量电导，dV/dI才是负增量输入电阻](/images/pi02/ill04_negative_impedance.png)

## 五、为什么低损耗输入LC会把两个“好系统”接成坏系统

假设输入路径包含：

```text
Rs = 0.08 Ω
L = 10 µH
Ceff = 22 µF
```

本教学模型额外假设转换器控制有效带宽约40 kHz，因此10.73 kHz被动LC谐振区可能落在负增量输入行为显著的频段。带宽以内的`Zin(jω)`仍可能具有明显幅相变化，不能据此把它当成固定纯负电阻；真实项目必须测量复数`Zin(f)`。[3][7][8]

LC谐振频率为：

```text
f0 = 1 / (2π√LC)
   = 10.730 kHz
```

仅靠0.08 Ω路径电阻阻尼时，模型扫频得到的源输出阻抗峰值约为：

```text
|Zs|max ≈ 5.722 Ω，峰值约在10.730 kHz
```

而转换器在12 V、100 W工作点的低频负增量输入阻抗幅值只有1.44 Ω；到9.6 V时进一步降到0.9216 Ω。

还要先排除一个更简单的原因：DC路径压降。本案例的Line Transient源端终值是10.8 V，若只考虑`Rs=0.08 Ω`和100 W恒功率负载，稳态DUT输入满足：

```text
VDUT² - 10.8×VDUT + 0.08×100 = 0
VDUT = 10.000 V
```

无振铃时，它距离8.5 V等效UVLO下降阈值仍有1.5 V。这样才能把“动态振铃把VIN推过UVLO”与“DC压降本身已经不够”区分开。真实项目还必须加入电感DCR、连接器、适配器容差、效率误差和温升后的路径电阻。

问题不在于“电感会掉压”这么简单，而在于：

1. LC在谐振附近把源输出阻抗抬高；
2. 在闭环仍维持调节的范围内，转换器为了维持功率，Vin下降时继续增加Iin；
3. 更大的Iin又在线缆和电感上制造更大压降；
4. 输入端等效阻尼被削弱，振铃可能被持续放大；
5. 最终进入UVLO、限流或hiccup，系统从小信号问题转成大信号保护循环。

单独测试时，适配器可能稳定，输入滤波器也没有损坏，DC-DC自身输出环路同样有足够相位裕度；但三者互连后的**minor loop**仍可能不稳定。[3][4]

这也是为什么只调输出补偿可能没有用：首错发生在转换器输入引脚，VOUT只是后续受害者。

![图5：输入LC源阻抗曲线。无专用阻尼时峰值为5.722 Ω、约10.730 kHz；加入0.33 Ω与100 µF串联的并联阻尼支路后，峰值降到0.419 Ω、约5.836 kHz。纯CPL的1 Ω线只用于模型内幅值示意](/images/pi02/ill05_impedance_curves.png)

## 六、Middlebrook怎么用：幅值交叉不是振荡判决器

在以下前提成立时：

- 上游源/滤波器子系统单独稳定；
- 下游转换器子系统单独稳定；
- 接口边界和阻抗方向定义一致；
- 系统可在该工作点附近用线性SISO小信号模型描述；
- 互连良定；
- `Tm`没有右半平面极点；若存在，则必须在Nyquist判据中显式计数；

可定义minor-loop gain：

```text
Tm(s) = Zs(s) / Zin(s)
```

若所有频率上：

```text
|Tm| < 1
```

则`Tm`轨迹被限制在以原点为中心的单位圆内，不会通过或包围`−1`；在上述极点前提下，这是整体稳定的一条**保守充分条件**。若`Tm`存在右半平面极点，必须按Nyquist的极点和环绕数关系完整判断。[7]

但它不是普遍必要条件。正确工程读法是：

|看到什么|可以得出什么|不能直接得出什么|
|-|-|-|
|所有频率`|Zs|<|Zin|`|通过保守幅值筛查|不能代表所有大信号条件都通过|
|两条幅值曲线交叉|需要继续检查相位和Nyquist|不能直接宣布系统一定振荡|
|时域出现持续振铃|当前配置存在动态风险|不能只凭波形确定一定是输入minor loop|
|已经进入UVLO/hiccup|需要做大信号first-error分析|不能继续用线性阻抗比代替故障时间线|

“源阻抗最好比输入阻抗低很多”是合理的工程目标。项目可以按风险自行规定额外幅值裕量；Vicor资料给出的十倍关系相当于20 dB，是其保守工程实践，不是Middlebrook数学定律。[6]

如果系统有多颗转换器共用输入母线、多端口耦合或共模/差模转换，单一标量`Zs/Zin`可能不够，需要阻抗矩阵和广义Nyquist。

![图6：Middlebrook工程读法。所有频率上|Tm|小于1是有前提的保守充分条件；幅值曲线交叉以后必须继续检查相位、右半平面极点和Nyquist轨迹，不能直接宣布振荡](/images/pi02/ill06_middlebrook.png)

## 七、Line Transient怎样测，才没有把电源设定值当成DUT输入

### 1. 激励必须在接入DUT后重新确认

测试条件至少包括：

- 起始Vin、终止Vin；
- 上升沿和下降沿`dV/dt`；
- 重复率和驻留时间；
- Iout、工作负载、温度和系统状态；
- 源限流、OVP、下拉或吸收能力；
- 实际线束、连接器、LISN、滤波器和CIN。

输入电容会显著减慢发生器边沿。下降沿时，如果激励器不能吸收CIN中的能量，设定的下降沿根本不会真正到达DUT。[1][2]

不得为了得到更漂亮的边沿拆掉产品实际CIN。这样测到的是测试夹具，不是产品。

### 2. 最小同步测量通道

建议按优先级布置：

1. 电源或适配器输出端电压；
2. DUT连接器处、滤波器之前的VIN；
3. 转换器VIN引脚处、滤波器之后的VIN；
4. 输入电流；
5. EN/UVLO分压节点；
6. switch node或电感电流；
7. VOUT；
8. PGOOD；
9. RESET/POR。

通道不够时分两轮测，也必须保留一个共同参考信号和相同触发条件，才能对齐时间线。

### 3. 耦合与探头

- 绝对VIN、UVLO阈值和VOUT窗口使用DC耦合；
- 可额外开AC耦合通道放大观察小信号振铃，但它不能独立证明绝对电压没有越限；
- 使用短地弹簧、同轴焊接或合适的差分探头；[12]
- 电流探头要检查带宽、饱和、极性和与电压通道的时延；
- 临时电流环会增加电感，分流器会增加压降，必须记录其对被测系统的扰动。

### 4. 触发与记录

可以用PGOOD下降沿或RESET断言触发，但预触发必须足以覆盖首错之前的完整输入动态。具体比例由记录深度、复位周期、保护恢复时间和触发稳定性决定，不能当成统一限值。数字信号只是稳定触发源，不是默认根因。

记录长度必须覆盖：

- 输入振铃开始；
- UVLO越阈；
- switch node停止；
- VOUT开始下降；
- PGOOD和RESET延时；
- 保护恢复或下一次hiccup。

## 八、first-error时间线：最后看到RESET，不等于RESET先错

本篇用人为设定的合成时间线说明判读方法。下列时间点不是由前述小信号阻抗模型直接仿真得到，也不代表通用保护延时。合成监控逻辑假设：8.5 V是折算到转换器VIN的UVLO下降阈值；内部UVLO在越阈25 µs后确认；VOUT越窗后PGOOD去抖50 µs；RESET由PGOOD驱动并在70 µs后断言。

|相对时间|信号|观察|
|-:|-|-|
|0 µs|源端指令|12.0 V降到10.8 V|
|20 µs|滤波前VIN|保持在输入范围内|
|45 µs|转换器VIN引脚|约10 kHz振铃，下降穿过8.5 V等效UVLO阈值|
|55 µs|转换器VIN引脚|到达8.2 V最低点|
|70 µs|内部UVLO|经过25 µs合成去抖/传播延时后确认|
|85 µs|Switch node|UVLO确认后停止开关|
|130 µs|VOUT|跌出允许窗口|
|180 µs|PGOOD|内部去抖后下降|
|250 µs|RESET|Supervisor延时后断言|

因此因果链是：

```text
输入源/滤波器交互
→ DUT VIN越过UVLO
→ 转换器停止开关
→ VOUT放电下降
→ PGOOD失效
→ RESET断言
```

![动画1：首错沿时间推进。源端稳定后，DUT VIN先振铃并越过UVLO，随后才停止开关、VOUT下降、PGOOD失效和RESET断言](/images/pi02/anim01_first_error.gif)

常见分叉：

### A. 源端正常，滤波后VIN先振铃

优先查线缆、连接器、LISN、差模电感、CIN有效值和输入阻抗交互。

### B. 适配器输出先跌落或进入限流

优先查源额定能力、峰值功率、限流方式、hiccup、线缆压降和输入浪涌。这是大信号源能力问题。

### C. VIN一直正常，VOUT或电感电流先异常

回到Load Transient、输出环路、限流、输出电容和功率级。

### D. 电源轨与PGOOD正常，RESET先断言

查Supervisor、Watchdog、Reset routing、时钟和软件，不要继续盲目堆电容。

不同器件的PGOOD和RESET可能异步动作、带阈值/迟滞/去抖，也可能由独立Supervisor或Watchdog控制；本例顺序只服务于first-error教学，不能外推为通用时序。[11]

## 九、输入阻抗怎样测：曲线必须带工作点和接口边界

输入阻抗不是一条脱离条件的器件标签。至少覆盖：

- 低、标称、高输入；
- 轻、中、满载；
- 冷机、室温、热机；
- PWM、PFM、跳脉冲或其他控制模式；
- 实际CIN和偏置条件。

FRA或网络分析测量时：

1. 在接口处注入足够小的扫频扰动，保持线性；
2. 注入量同时要高于开关噪声，必要时使用同步窄带检测；
3. 监控注入器DC压降，避免工作点被移动；
4. 做thru或open/short/load校准，并用已知阻抗验证夹具；
5. 明确`Zs`和`Zin`在哪个接口分开；
6. 不要把同一颗输入电容同时算进源侧和负载侧；
7. 记录电流互感器饱和、分流器功耗和寄生电感。

测得幅值和相位后，先做`|Zs|`与`|Zin|`筛查；出现交叉再分析`Tm=Zs/Zin`的相位和Nyquist。不要只截一张幅值曲线就下稳定或不稳定结论。[7][8]

## 十、Fail以后怎么改：先按首错分流，不要随机换电容

### 路径一：源端先掉

- 提高适配器峰值能力或调整限流策略；
- 降低线缆和连接器电阻；
- 确认Remote Sense参考点和稳定性；
- 减少不必要的串联器件；
- 检查启动和负载切换是否同时发生。

Remote Sense只能补偿一部分DC/低频压降，不能消除线缆电感。

### 路径二：滤波后VIN振铃

- 降低LC的Q；
- 校核电感DCR、饱和电流和实际L；
- 用带适当ESR的Bulk提供储能与阻尼；
- 增加串联`RD-CD`后并联在滤波输出的阻尼支路；
- 调整L/C，使阻抗峰离开危险区；
- 缩短线束或降低路径电感；
- 重新评估LISN和EMI滤波器的完整网络。

并联`RD-CD`、利用DCR/ESR或改变L/C各有不同的损耗、储能和EMI代价，不能把某一种方案当成通用处方。[3][4][5]

本篇模型在滤波输出并联`0.33 Ω + 100 µF`串联支路后，扫频结果从：

```text
无专用阻尼：|Zs|max ≈ 5.722 Ω
```

下降到：

```text
有阻尼：|Zs|max ≈ 0.419 Ω，峰值约在5.836 kHz
```

故障条件的源端终值为10.8 V，对应极简DC模型中的稳态DUT VIN为10.0 V。在本文额外采用的纯恒功率负阻抗近似中，`|rin|=10.0²/100=1.000 Ω`。若再假定相关频段内`|Zin|≈1.000 Ω`，则`max|Zs|/|Zin|`从约5.722降到约0.419。这只是极简模型内的幅值示意，不构成对真实转换器的Middlebrook或Nyquist验证。9.6 V工作点仅作为另一独立低线筛查角，不与本次Line Transient故障条件混用。真实项目必须使用实测复数`Zin(f)`，并检查相位、时域、EMI、浪涌和功耗。

![动画2：输入阻尼A/B。无专用阻尼时Zs峰值为5.722 Ω；加入0.33 Ω与100 µF串联的并联支路后降为0.419 Ω。动画只证明模型幅值变化，不替代真实Zin相位和Nyquist验证](/images/pi02/anim02_damping.gif)

这组`0.33 Ω + 100 µF`是教学初值，不是通用处方。真实设计要校核阻尼电阻脉冲功率、电容偏压、温度、寿命、ESR/ESL、布局和EMI。

### 路径三：UVLO或迟滞配置不合理

- 回到Exact-model Datasheet确认下降阈值、上升阈值、迟滞和去抖；
- 检查分压器误差、偏置电流、噪声和布局；
- 评估阈值是否与系统允许输入范围、线缆压降和保护目标一致。

不能为了让复位消失就盲目降低UVLO。阈值过低可能让转换器在占空比、热、限流或磁件饱和风险区继续工作。

### 路径四：VIN正常而VOUT先错

回到输出环路、Load Transient、输出电容、补偿、限流和布局。此时修改输入滤波器没有证据支撑。

![图8：复位Debug决策树。按首错分为源端先掉、滤波后VIN先振铃、VIN正常而VOUT先错、电源正常而RESET先错四条路径，避免随机堆电容或放宽阈值](/images/pi02/ill08_debug.png)

## 十一、整改后怎样复测，才算真正关闭问题

修复不是“新波形看起来顺眼”，而是回到原故障条件完成A/B闭环。

### 1. 原条件复现

- 同一DUT版本；
- 同一适配器和固件；
- 同一线束、连接器、LISN和滤波器；
- 同一输入阶跃、负载、温度和工作负载；
- 同一探点、带宽、耦合、采样率、记录长度和触发；
- 同一预触发比例和判定窗口。

### 2. 必须复测

- 源端、滤波前和DUT引脚VIN；
- IIN、UVLO、SW/IL、VOUT、PGOOD和RESET时间线；
- `Zs`、`Zin`幅相与minor-loop分析；
- 低线、满载、热机最差角落；
- 不同线束和适配器；
- Conducted EMI；
- 启动浪涌、热插拔风险和阻尼电阻脉冲功率；
- 长时间运行和重复次数。

### 3. 关闭标准

同时满足：

1. DUT引脚VIN不越过项目下限和UVLO；
2. 输入振铃按规定幅度和时间衰减；
3. VOUT、PGOOD和RESET没有异常；
4. 阻抗幅相满足项目判据或通过完整Nyquist分析；
5. EMI、效率、温升、启动和保护没有因整改退化；
6. 原始波形、脚本、BOM和测试配置可追溯。

只有这样，才能证明修掉的是根因，而不是把复位延后或换了一个条件隐藏。

推荐结论写法：

```text
故障条件：
12.0 V→10.8 V line transient，90 W输出，产品适配器与1.5 m线束，
实装10 µH输入电感、有效22 µF输入电容。

第一错误：
DUT VIN出现约10 kHz振铃，在45 µs穿过折算后的8.5 V UVLO阈值，
55 µs到达8.2 V最低点；本合成监控逻辑在70 µs确认UVLO，
SW停止早于VOUT、PGOOD和RESET异常。

频域证据：
无专用阻尼时源输出阻抗峰值约5.722 Ω；
故障条件稳态DUT VIN为10.0 V；纯恒功率近似下低频|rin|为1.000 Ω。

整改：
增加经功耗校核的0.33 Ω + 100 µF串联并联阻尼支路，并优化线束。

复测：
源阻抗峰值降至约0.419 Ω；原条件下DUT VIN不越过UVLO，
实测复数Zin、相位与时域复核符合项目规则，
VOUT/PGOOD/RESET正常，EMI、浪涌、效率和温升复测通过。
```

## 写在最后

这篇只需要记住四句话：

> **Load Transient改变负载；Line Transient向上游输入源或规定参考面施加电压变化，并实测DUT输入端响应，两者不能互相代替。**  
> **适配器、线缆、连接器、LISN和输入滤波器共同构成频率相关源阻抗。**  
> **恒功率负载只在一定工作点和频段呈负增量输入阻抗，Middlebrook幅值关系也有严格前提。**  
> **最后看到RESET，不代表RESET先错；先建立VIN→UVLO→SW→VOUT→PGOOD→RESET的first-error时间线。**

下一步不是继续盲调输出端，而是把原适配器、原线束、原滤波器和原高功耗负载重新接回来，证明首错已经消失，并确认EMI、效率、温升、启动和保护没有被新的阻尼方案破坏。

## 🔧 工程师速查（附录）

### 开测前

- [ ] 电源型号、限流、Remote Sense和输出电容已记录
- [ ] 线缆长度/线径、连接器、LISN和输入滤波器实装值已记录
- [ ] DUT输入、输出负载、温度、模式和工作负载已固定
- [ ] 源端VIN、滤波前VIN、DUT VIN和输入电流可同步观察
- [ ] UVLO、SW/IL、VOUT、PGOOD和RESET中至少保留能建立首错链的通道
- [ ] 绝对电压判断保留DC coupling，探头带宽、接地和通道时延已检查

### 判读顺序

1. 先检查DC工作点与路径压降是否已经越限；
2. 再按时间顺序寻找源端、DUT VIN、UVLO、SW/IL、VOUT、PGOOD和RESET中的第一错误；
3. 若怀疑输入LC交互，必须在实际工作点测复数`Zs(f)`、`Zin(f)`和相位；
4. 幅值交叉后继续检查右半平面极点与Nyquist，不把交叉直接写成振荡；
5. 进入UVLO、限流或hiccup后，改用大信号时间线分析，不再硬套小信号阻抗比。

### 修复闭环

- [ ] 回到原适配器、原线束、原滤波器、原负载和原温度做A/B复测
- [ ] DUT VIN不再越过Exact-model欠压或输入范围限值
- [ ] 输入振铃的幅度、频率和衰减满足项目判据
- [ ] VOUT、PGOOD和RESET异常链消失
- [ ] EMI、效率、温升、启动、浪涌和保护没有退化
- [ ] 原始波形、阻抗数据、脚本、BOM和测试配置可追溯
