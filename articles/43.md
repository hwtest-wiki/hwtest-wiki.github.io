# 屏没坏：FPC 只多吃 0.37 dB，MIPI 电气判定就能从过变挂

<div class="article-meta"><span class="badge">📘 模块六 · 高速接口一致性测试 · 手机家族第 1 篇</span><span class="badge">⏱ 约 15 分钟</span><span class="badge qr">🔧 含工程师速查</span></div>


同一块屏、同一版软件，手机平放时一切正常；机身一扭、FPC 折到某个角度，屏上突然闪一道横条，甚至黑一下又回来。

最容易走的弯路，是先换屏、再换主板、最后把问题写成“连接器接触不良”。可如果把 FPC 在 2.5 Gbps/lane 下的插损从 **9.81 dB** 扫到 **10.19 dB**，只差 **0.37 dB**，本篇同一套物理模型算出的眼高会从约 **90.3 mV** 掉到 **79.3 mV**：前一帧还在 80 mV 教学线上方，后一帧已经擦穿。

电气层一翻，位错误就往协议层冒；CRC/ECC 把坏包丢掉，最后落到用户眼里，才变成亮点、横条、掉帧和“黑一下”。**屏没坏，通道裕量先没了。**

## 一、先认清主角：CSI-2 送进来，DSI 送出去

MIPI 不是某一根线的名字。它是一整套移动与嵌入式设备接口规范。屏幕和摄像头这条链上，最容易混在一起的是“协议”和“物理层”：

- **CSI-2**：摄像头 sensor → SoC，负责把像素和控制信息送进主控。
- **DSI**：SoC → 显示模组，负责把画面与命令送到屏。
- **D-PHY / C-PHY**：承载 CSI-2 或 DSI 的物理层，决定线怎么拉、时钟怎么来、眼图怎么判。

### D-PHY：数据差分对外，再带一根转发时钟

每条 data lane 是一对差分线，链路还带公共差分 clock lane。高速数据双沿采样，所以 2.5 Gbps/lane 对应的 clock 是 1.25 GHz。

它的好处是接收端不用从 data 里重新恢复时钟；代价也很直接：**clock lane 和 data lane 在板上多走出来的每一皮秒偏斜，都会直接吃掉采样窗。**

### C-PHY：三根线一组，把时钟藏进状态迁移

C-PHY 每组是三根线，叫一个 **trio**。三线相对电平和状态迁移共同编码信息，链路没有独立 clock lane。接收端必须靠 CDR / golden PLL 恢复采样相位。

所以 C-PHY 的测试重点不是“找那根时钟线”，而是：三电平投影眼开得够不够、CDR 对相位抖动跟得住多少、报告里的 golden PLL 参数是否写清。

![图2：MIPI 链路角色图。CSI-2 把摄像头 sensor 的像素送进 SoC，DSI 把 SoC 处理后的画面送到显示模组。D-PHY 使用差分 data lane 加独立 clock lane，需要量 clock/data skew；C-PHY 使用三线 trio 和嵌入式时钟，需要按 golden PLL / CDR 判三电平投影眼](/images/43/ill02_whatis.png)

## 二、三副波形讲清 MIPI：转换、转发时钟、三电平恢复

### 2.1 LP / HS 不是两个速率档，是两套电气状态

D-PHY 平时可以停在 LP-11 等低功耗状态。进入高速传输前，P/N 两根线会经历 LP 请求、LP-00、HS prepare、HS zero，最后才开始 HS burst。

这段波形最大的反差是电平量级：LP 是约 1.2 V 的单端状态，HS 是约 200 mV 的小摆幅差分。**如果只保存 P-N 差分波形，LP-11、LP-01、LP-00 很可能全被你“减没了”。**

### 2.2 D-PHY 的眼开着，不代表时钟在眼心采样

本篇固定 2.5 Gbps/lane：

- 1 UI = 400 ps；
- 半个采样窗 = 200 ps；
- 接收 setup/hold 教学预算取 42 ps；
- clock jitter 教学预算取 24 ps。

因此剩余裕量是：

**margin = 200 ps − clock/data skew − 42 ps − 24 ps**

当 skew 接近 **134 ps**，裕量穿零。这里最值得记住的不是 134 这个教学数字，而是测法：**D-PHY 必须把“data 眼图”和“clock/data skew”分开判。**

### 2.3 C-PHY 的幅度没变，CDR 跟不上仍会挂

本篇生成 6500 个三电平符号，加入 12 MHz 周期抖动，再用一阶 CDR 相位误差模型计算残余抖动。CDR 带宽从 1 MHz 扫到 45 MHz 时，三电平眼高始终约 148~150 mV，真正先跨线的是眼宽：

- 约 9.2 MHz：眼宽约 0.372 UI，FAIL；
- 约 10.2 MHz：眼宽约 0.382 UI，PASS。

也就是说，幅度看起来几乎没动，采样相位却从站不稳变成站稳了。**golden PLL 不是软件里的装饰选项，它就是测量条件。**

![图3：三种 MIPI 关键波形。左为真实连续 LP-11/01/00 到 HS burst 电压轨迹；中为 D-PHY 2.5 Gbps/lane 的 400 ps UI 采样预算，固定 setup/hold 与时钟抖动共吃 66 ps，clock/data skew 约 134 ps 后裕量穿零；右为真实生成的 C-PHY 三电平投影眼，CDR 带宽约 10 MHz 后眼宽跨过教学线](/images/43/ill03_arch.png)

### 动图①：HS prepare 不是越长越稳

本篇固定 T_LPX = 60 ns、T_HS-ZERO = 100 ns，扫描 T_HS-PREPARE 30→100 ns。按公开资料常见的 D-PHY v1.x 量级公式建立教学窗口：

- PREPARE 下界约 41.6 ns；
- PREPARE 上界约 87.4 ns；
- PREPARE + ZERO 还要满足约 149 ns 的总时间。

真实扫描在约 **49 ns** 时从 FAIL 翻成 PASS，约 **87 ns** 后又翻回 FAIL。太短，HS zero 还没站稳；太长，又越过 prepare 上界。

![动图1：D-PHY LP-11 进入 HS 的真实连续波形。旋钮扫描 T_HS-PREPARE 30~100 ns，LPX、PREPARE 下界、PREPARE 上界、PREPARE+ZERO 四项逐项判定；约 49 ns 进入 PASS 窗口，约 87 ns 离开窗口。图中限值为教学判据，正式报告以对应版本 CTS 为准](/images/43/anim01_hslp.gif)

## 三、版本和单位：先写清 Gbps/lane 还是 Gsym/s/trio

| 物理层 | 示例版本 | 线速率 | 先换算什么 |
|---|---:|---:|---|
| D-PHY | v1.2 | 2.5 Gbps/lane | UI = 400 ps；clock = 1.25 GHz |
| D-PHY | v2.x | 4.5 Gbps/lane | UI ≈ 222 ps |
| D-PHY | v2.5 | 9.0 Gbps/lane | UI ≈ 111 ps |
| C-PHY | v1.0 | 2.5 Gsym/s/trio | ×2.28 ≈ 5.7 Gbps/trio |
| C-PHY | v3.0 | 6.0 Gsym/s/trio | ×2.28 ≈ 13.7 Gbps/trio |

最常见的两种算错：

1. 把 D-PHY 的 clock 频率当成 data 线速率，示波器带宽跟着偷减半。
2. 把 C-PHY 的 Gsym/s 直接写成 Gbps，UI、吞吐和 CDR 设置全错一轮。

![图4：D-PHY 与 C-PHY 版本速率表。D-PHY 报 Gbps/lane，并列出 2.5、4.5、9.0 Gbps/lane 对应 UI；C-PHY 报 Gsym/s/trio，2.5 与 6.0 Gsym/s 分别换算约 5.7 与 13.7 Gbps/trio。底部强调先确认 PHY、版本、lane/trio 数和 CTS 版本](/images/43/ill04_versions.png)

## 四、D-PHY、C-PHY、M-PHY 同属 MIPI，不等于能互抄测法

三者都追求短距、高速和低功耗，但线结构、时钟和状态机并不相同：

| 项目 | D-PHY | C-PHY | M-PHY |
|---|---|---|---|
| 线结构 | 差分 data + 独立 clock | 三线 trio | 独立差分 TX/RX |
| 时钟 | 源同步转发 | 三相数据里恢复 | 串行数据里恢复 |
| 关键 Tx 项目 | 眼图、clock/data skew、LP/HS | 三电平眼、CDR、LP/HS | 眼图、均衡、Gear |
| 低功耗状态 | LP 单端状态机 | LP 单端状态机 | PWM / 低速状态，流程不同 |

一句话记：**D 转发，C 嵌入。** 但别把这句口诀继续简化成“C-PHY 就是三根 D-PHY”，也别把 UFS 的 M-PHY 状态机和 CTS 直接搬过来。

![图5：D-PHY、C-PHY、M-PHY 对照。逐行比较线结构、时钟、低功耗状态、Tx/Rx 测试重点与不可混用项；D-PHY 记“D 转发”，C-PHY 记“C 嵌入”，正式测试仍要按具体版本和方向确认](/images/43/ill05_compare.png)

## 五、MIPI 测三类：转换、发送端、接收端

### 5.1 LP ↔ HS 转换

看的是状态顺序、电平与时间：

- LP-11 / LP-01 / LP-00 是否完整；
- T_LPX、T_HS-PREPARE、T_HS-ZERO、退出时间是否落窗；
- P/N 单端电平有没有毛刺；
- HS burst 的第一段同步内容是否干净。

### 5.2 Tx 发送端电气

D-PHY 至少分两张结论：

- data lane 真眼是否过模板；
- clock/data skew 的采样裕量是否大于零。

C-PHY 则要给三电平眼、恢复时钟条件与 golden PLL 参数。只贴一张漂亮眼图、不写 PLL，别人无法复现。

### 5.3 Rx 压力与通道

Rx 不是看“它发得好不好”，而是故意灌一个接近边界的脏信号，问它还能不能正确接收。压力信号必须先在 **Rx 引脚参考面**校准，再接 DUT。

如果器件没有 BER 引脚，就读协议层的 CRC、ECC、错误计数与帧丢失。**只盯屏有没有花，低概率错误可能跑一天都等不到；错误计数器却早就开始涨。**

![图6：MIPI 三类测试。LP/HS 转换扫 prepare/zero/exit 并保留单端状态；Tx 电气对 D-PHY 分别判眼图和 skew、对 C-PHY 判三电平眼与 golden PLL；Rx 压力先在参考面校准，再扫 FPC 损耗、SJ 与 CDR 条件并回读错误计数](/images/43/ill06_test3.png)

### 动图②：D-PHY skew 把采样沿推出眼心

扫描 clock/data skew 0→220 ps，data 眼本身一直画在左侧，采样沿却一路向右走。到约 **134 ps** 后，固定预算和 skew 已经装不进半个 UI，剩余采样裕量从正数翻成负数。

这张图专门纠正一个误区：**眼图 PASS 不等于链路 PASS。** 转发时钟架构必须再问一句，时钟到底落在眼的哪儿。

![动图2：D-PHY 2.5 Gbps/lane 的 clock/data skew 扫描。半个 UI 采样窗固定为 200 ps，setup/hold 教学预算 42 ps、clock jitter 24 ps，skew 从 0 增到 220 ps；约 134 ps 时剩余裕量穿零，采样沿跨出安全窗](/images/43/anim02_skew.gif)

### 动图③：C-PHY CDR 带宽把三电平眼宽救回来

旋钮从 1 MHz 扫到 45 MHz。三电平眼高几乎不变，残余相位抖动持续下降，眼宽在约 **10 MHz** 后跨过 0.38 UI 教学线。

这张图回答的是：为什么两个人拿同一份 C-PHY 波形，可能一个判 FAIL、一个判 PASS？先别争眼图算法，先比对 **golden PLL / CDR 带宽**是不是同一套。

![动图3：C-PHY 三电平投影眼与时钟恢复。固定 2.5 Gsym/s、12 MHz 周期抖动，扫描 golden PLL/CDR 带宽 1~45 MHz；眼高约 148~150 mV 基本不变，眼宽从约 0.31 UI 增至 0.53 UI，并在约 10 MHz 后跨过 0.38 UI 教学线](/images/43/anim03_cphy.gif)

### 动图④：FPC 插损如何闭环到花屏和掉帧

本篇把 FPC + 连接器插损从 2 dB 扫到 18 dB。每一帧都重新生成 6000 bit 码流、跑一阶有损通道、折叠余辉眼并测眼高眼宽，再把归一化眼裕量映射到教学 BER 模型，最后算每帧坏像素和每分钟掉帧。

真实翻转发生在约 **10 dB**：

- 9.81 dB：约 90.3 mV / 0.493 UI，PASS；
- 10.19 dB：约 79.3 mV / 0.441 UI，眼高先擦穿，FAIL。

这里不要把 10 dB 抄进测试规范。该数字只属于本篇这组发送端、速率、噪声与教学模板。应该带走的是**闭环方法**：插损 → 眼图 → 错误计数 → 画面现象。

![动图4：FPC 插损闭环扫描。D-PHY 2.5 Gbps/lane 下把 FPC+连接器插损从 2 dB 扫到 18 dB，每帧真实计算眼高、眼宽、归一化裕量、教学 BER、坏像素与掉帧；约 10 dB 时眼高先跨过 80 mV 教学线，随后 CRC 丢包、横条、掉帧与黑帧快速增加](/images/43/anim04_fpc.gif)

## 六、台面怎么搭：Tx 和 Rx 是两张完全相反的图

![图7：MIPI 测试流程总览。Tx 台面问“它发出来干不干净”，让 DUT 输出重复 HS burst，探头落在 Tx 参考面，保留 LP→HS 原始轨迹后再折 HS 真眼，并单独量 D-PHY skew；Rx 台面问“故意给脏信号还认不认”，压力源先在 Rx 参考面校准，再扫参数并回读 CRC/ECC/错误计数与丢帧](/images/43/ill07_bench.png)

### 6.1 Tx Setup：同一次采集，先看状态，再折眼

正确顺序：

1. 控制主机让 SoC、sensor 或显示桥进入重复 HS burst / 测试码型。
2. 差分探头落在 Tx 参考面附近，同时保存 P、N 单端轨迹。
3. 先检查 LP-11/01/00 与 HS 进入/退出，再切出 HS 片段累积眼图。
4. D-PHY clock lane 单独接入通道，计算 clock/data skew。
5. 去嵌扣掉探头到球脚之间的板、连接器与夹具。

![Setup Diagram 1：MIPI Tx 台面。控制软件让被测 Tx 重复发 D-PHY 2.5 Gbps/lane HS burst；探头落在经过连接器/FPC 的参考点，实时示波器同一次采集保存 LP 单端状态与 HS 真眼，屏上显示 6 dB 通道后的真实眼图和教学模板；底部列出参考面、单端/差分、clock lane 与去嵌要求](/images/43/fig_setup_tx.png)

### 6.2 Rx Setup：压力信号先校准，再接 DUT

正确顺序：

1. 码型/抖动发生器输出 D-PHY 或 C-PHY 压力序列。
2. ISI 板和可变损耗模拟 PCB、FPC 与连接器。
3. DUT 先不接，示波器放在 Rx 引脚参考面校准压力眼。
4. 校准完成后接回 DUT，扫描损耗、SJ、幅度与 CDR 条件。
5. 从 CRC、ECC、错误计数或丢帧统计回读接收结果。

![Setup Diagram 2：MIPI Rx 台面。码型/抖动发生器经过 ISI 板与可变损耗，在 Rx 引脚参考面先接示波器校准；正式测量时改接显示模组或 SoC 接收端，从协议分析软件回读 CRC/ECC/错误计数与丢帧。右侧屏幕显示 C-PHY 三电平眼宽随 golden PLL 带宽变化并在约 10 MHz 后跨过教学线](/images/43/fig_setup_rx.png)

## 七、报告里必须写什么

只写“MIPI eye PASS”几乎等于没写。至少补齐：

- 物理层与版本：D-PHY 还是 C-PHY，对应哪个版本 CTS；
- 协议与方向：CSI-2 / DSI，Tx 还是 Rx；
- lane / trio 数与线速率，单位是 Gbps 还是 Gsym/s；
- 测试模式、码型、HS burst 触发条件；
- 参考面、探头、夹具、去嵌文件与带宽；
- D-PHY 的 clock/data skew 计算方法；
- C-PHY 的 golden PLL / CDR 参数；
- 压力信号的校准值与校准顺序；
- 第一处 PASS↔FAIL 翻转，以及翻转前后原始波形；
- 协议错误计数、CRC/ECC、帧丢失是否与电气量同向变化。

**正式限值必须来自对应版本的 MIPI D-PHY / C-PHY CTS，以及 CSI-2 / DSI 协议一致性文档。** 本文的 80 mV、0.34 UI、0.38 UI 与约 49~87 ns 只用于教学演示，不得直接复制到认证报告。

## 八、花屏别先换屏：按五层排

1. **配置 / lane / 速率**：整屏偏色、分辨率错、帧率固定减半，先读寄存器与协商结果。
2. **LP ↔ HS 转换**：规律横条、周期花块、偶发闪线，抓 LP-11/01/00 和进入/退出。
3. **HS 电气 / FPC**：弯折才花、高温才错、高速档才掉，量眼、skew、插损与串扰。
4. **CSI-2 / DSI 协议**：特定区域花、包长或格式错，查 ECC、CRC、虚拟通道与映射。
5. **供电 / 时钟域**：背光或 sensor 瞬变时才错，对齐电源跌落、PLL 解锁与错误计数。

真正有说服力的根因证据，不是“换一块屏好了”，而是三个时间戳对齐：

**FPC 插损或 skew 变差 → 眼图/采样裕量变差 → CRC/ECC 与丢帧同步增加。**

![图8：MIPI 花屏分层调试图。按配置/lane/速率、LP↔HS 转换、HS 电气/FPC、CSI-2/DSI 协议、供电/时钟域五层排查；下方用约 10.2 dB 插损后的真实 FAIL 眼图连接到位错误、CRC/ECC、坏包丢弃和花屏/掉帧闭环，强调先证明电气量与错误计数同向变化](/images/43/ill08_debug.png)

## 九、一句话收尾

MIPI 难测，不是因为“眼图特别神秘”，而是同一组线上同时塞了三件事：

**LP/HS 两套电气状态、D-PHY 的转发时钟采样、C-PHY 的嵌入式时钟恢复。**

所以记住这句：

> **LP/HS 看转换，D-PHY 多量 skew，C-PHY 写清 CDR，FPC 一定闭环到错误计数。**

## 🔧 工程师速查（附录）

### 四个教学扫描真值

| 扫描 | 区间 | 真实翻转 | 结论 |
|---|---:|---:|---|
| T_HS-PREPARE | 30~100 ns | 约 49 ns 进 PASS；约 87 ns 回 FAIL | 太短、太长都不行 |
| D-PHY clock/data skew | 0~220 ps | 约 134 ps 后 margin < 0 | 眼 PASS 仍可能采错 |
| C-PHY CDR 带宽 | 1~45 MHz | 约 10 MHz 后眼宽过线 | PLL 参数决定判读 |
| FPC 插损 @ 1.25 GHz | 2~18 dB | 约 10 dB 后眼高先擦线 | 闭环到 CRC/掉帧 |

> 上表全部是本文统一物理模型的教学结果，不是正式 MIPI CTS 限值。

### Tx 快速检查表

- [ ] 确认 D-PHY / C-PHY、版本、方向、lane/trio 与速率单位。
- [ ] 进入重复 HS burst / 规范测试码型。
- [ ] 保存 P、N 单端原始轨迹，不只保存 P-N。
- [ ] 触发并量 LP-11/01/00、进入、退出、毛刺。
- [ ] HS 段单独折眼并套对应版本模板。
- [ ] D-PHY 单独量 clock/data skew。
- [ ] C-PHY 写清 golden PLL / CDR 条件。
- [ ] 写清参考面、探头、夹具、带宽与去嵌。

### Rx 快速检查表

- [ ] 压力源、ISI 板、SJ 与噪声设置可追溯。
- [ ] DUT 先断开，在 Rx 引脚参考面校准压力信号。
- [ ] 校准后再接 DUT，顺序不能反。
- [ ] 扫参数而不是只测单点，记录第一处翻转。
- [ ] 回读 CRC、ECC、错误计数、坏包与丢帧。
- [ ] 把电气翻转与协议错误时间戳对齐。

### 标准与资料入口

- MIPI Alliance D-PHY / C-PHY Specification 与对应 CTS。
- MIPI Alliance CSI-2 / DSI / DSI-2 Specification 与对应协议一致性文档。
- 示波器厂商的 MIPI D-PHY / C-PHY 一致性测试应用说明。
- 正式认证项目以目标产品、目标版本与授权 CTS 为唯一判据来源。
