# 板级数字信号完整性 SI 完整知识地图：从回流、反射到眼图和 BER，一条链路到底该怎么查

<div class="article-meta"><span class="badge">📘 模块三 · 信号完整性 SI · 收官知识地图</span><span class="badge">⏱ 约 20 分钟</span><span class="badge qr">🔧 含工程师速查</span></div>


一条 10 Gbit/s 链路偶尔误码，最容易出现的场面是：有人加大 CTLE，有人换更贵的线，有人盯着眼图说“像串扰”，还有人把示波器截图贴进报告。忙了一天，误码率没动。

问题通常不在某一个旋钮，而在顺序错了：**你还没说清楚测量参考面在哪，就想解释眼图；你还没确认回流是否连续，就想用均衡救；你看到一个小眼，就急着把原因唯一归给损耗。**

SI 的正确打开方式不是“背一堆名词”，而是把链路当成一个有输入、有路径、有观测点、有判决器的系统。下面这张地图就是这套系统的导航。

![图1：板级数字 SI 的统一链路。发射端有限边沿和输出阻抗，经过封装、PCB 走线、过孔、连接器，最后在接收端由采样/CDR 判决。Z0、S 参数、眼图和 BER 都必须注明各自的端口或参考面；换探头、夹具或参考面，数字不能直接横比。](/images/ss01/ill01_simap.png)

## 一、先画系统边界：信号和回流从来是一对

数字信号不是“从 A 脚跑到 B 脚”的一根电流。每一次电压跳变，都有一条去程电流和一条回流电流；高频时，回流会优先沿着**离信号最近、环路电感最低**的参考平面返回。信号跨层时，如果参考平面也变了，就需要在附近提供回流过孔或连续的平面耦合路径。

这句话能把很多貌似不相关的问题串起来：

- 参考面被槽切开，回流绕远：局部电感、辐射、串扰和阻抗不连续一起变坏；
- 差分对两根线不对称：一部分差模能量变成共模，EMI 可能先报警；
- 探头地线很长：测量工具自己又造了一个大回路，屏上的振铃未必来自 DUT；
- 换了夹具却直接比较 S21：测试参考面已经换了，曲线也就不再是同一道题。

所以每份 SI 记录的第一行不该是“眼高多少”，而应是：**从哪里激励、在哪个参考面观测、接收端怎样判决、夹具是否已校准或去嵌。**

## 二、传输线：RLCG 是模型，几何与回流才是实物

低速直流里，走线像一段很小的电阻；边沿足够快时，它更像一条分布参数传输线。最常用的每单位长度模型是 R、L、G、C：

- R：铜箔、过孔与趋肤效应带来的导体损耗；
- L：去程与回流组成的环路电感；
- G：介质漏损的等效支路；
- C：走线和参考平面之间、以及相邻线之间的电容。

![图2：RLCG 分布参数模型。低损耗近似下 Z0≈√(L/C)、传播速度 v≈1/√(LC)。它假设走线均匀、线性、只讨论一个传播模态；真实板卡的线宽、铜厚、玻纤、粗糙度、过孔和连接器需要场求解或实测。](/images/ss01/ill02_simap.png)

在低损耗近似下，可用 Unicode 纯文本公式记住两件事：

**Z0 ≈ √(L/C)**
**v ≈ 1/√(L·C)**

它们不是让你手算一块板的最终阻抗，而是帮你判断趋势：回流更远、环路更大，L 往往上升；走线更宽、离参考面更近，C 往往上升。具体叠层应交给板厂阻抗计算、2D/3D 场求解或 TDR coupon，而不是把某个“50 Ω 线宽”抄到所有板子上。

### 微带的有效介电常数：不要把 FR-4 标称 εr 直接塞进全部公式

表层微带一部分电场在空气、一部分在介质中，因此它看到的是有效介电常数 εeff，通常介于空气的 1 和板材的相对介电常数之间。内层带状线的场更多被介质包住，传播速度、损耗和串扰表现又不同。

![图3：微带线的场分布与有效介电常数。空气与介质共同参与，因此 εeff 不是简单的板材标称 εr。图中的约 6.4 ps/mm 是贯穿本文的教学示例，不是任何 FR-4 的通用规范值。](/images/ss01/ill03_simap.png)

材料数据表上的 Dk/Df 还会随频率、树脂比例、玻纤编织和测试方法变化。真正要交付的不是“我算过”，而是：**目标阻抗、叠层版本、板厂工艺、公差、coupon/TDR 验证方法和频率范围。**

### 差模、共模与模式转换

差分对不是两条各自独立的单端线。反相激励时主要是奇模，差分阻抗常近似为 Zdiff ≈ 2·Zodd；同相的共模则对应另一套场分布和阻抗。P/N 长度、过孔、焊盘、参考面或连接器的任何不对称，都可能把差模转换成共模。

这就是为什么“差分眼图尚可”并不保证“EMI 没事”：你还应关注 mixed-mode S 参数中的 Sdd、Scc，以及 Sdc/Scd 模式转换。

## 三、边沿决定频谱和电气长度：别只看标称时钟

一个 25 MHz 时钟若边沿只有 200 ps，它携带的有效高频成分远高于 25 MHz。对近似高斯响应，工程上常用：

**f≈0.35/tr**

这里 f 是与该上升时间相关的 3 dB 带宽近似，tr 是 10%～90% 上升时间。它是**模型关系**，不是串行接口合规带宽，也不是“示波器必须等于 0.35/tr”的固定规则。

![图4：边沿与电气长度。图中 f≈0.35/tr 是高斯近似；“单程延迟约达到 tr/6 就开始按传输线审视”是常用工程筛查规则。图中的临界长度由 6.4 ps/mm 教学传播延迟计算，不能替代某项目的叠层数据。](/images/ss01/ill04_simap.png)

另一个实用筛查是：当单程传播延迟接近或超过 tr/6，反射已可能在边沿尚未结束时回来，走线就应按传输线审视。它是提醒你“去看仿真和实测”的经验边界，不是任何标准的 pass/fail 数值。

## 四、反射与端接：Γ 的符号是电压，平方后才是功率

在一个明确的参考阻抗 Z0 下，负载 ZL 处的电压反射系数是：

**ΓV＝(ZL−Z0)/(ZL+Z0)**

ΓV 为正，反射电压与入射电压同向；为负，则反向。反射功率比不是 ΓV 本身，而是：

**反射功率比＝|ΓV|²**

![图5：反射系数的电压与功率区别。50 Ω 参考下 75 Ω 的 ΓV=+0.20，但反射功率比为 0.04；25 Ω 的 ΓV≈−0.33，功率比约 0.11。均为公式教学例，端口和频率范围必须随真实结果写明。](/images/ss01/ill05_simap.png)

端接的本质是管理反射能量和边沿：

- 点对点 CMOS 常从源端串阻开始看，使 Rout+Rs 接近走线 Z0，回到源端的反射被吸收；
- 接收端并联或 Thevenin 端接让负载接近 Z0，但要算直流功耗和偏置；
- AC 端接只在跳变时吸收高频分量，电容值和码型/占空比有关；
- 差分端接先确认它针对的是 Zdiff，分裂端接还会影响共模。

不要用“振铃压没了”作为唯一成功标准。串阻太大也会拉慢边沿、侵蚀时序；最好的验证是接收端可重复的眼余量/BER、完整的电压绝对最大值检查，以及真实业务与 EMI 的联合复验。

## 五、串扰：NEXT、FEXT 和回流是一件事的不同观察角度

相邻线的电场与磁场耦合会在受害线产生串扰。近端串扰 NEXT 在受害线靠近激励端的一侧观察；远端串扰 FEXT 在远端观察。实际波形的极性、宽度与幅度还受层叠、传播速度差、终端和测点影响，不能只背“哪个一定更大”。

![图6：串扰与回流。Aggressor 的去程和回流形成环路；Victim 的 NEXT/FEXT 来自电容与电感耦合。连续参考面、减少并行长度、增大间距和控制边沿是从根上降低耦合的路径。](/images/ss01/ill06_simap.png)

诊断串扰时，先做一个可证伪的 A/B：

1. 让 aggressor 固定码型翻转、victim 静止；
2. 两通道同时、同一带宽和同一接地方式采样；
3. 改变一项：关掉 aggressor、拉开并行、补回流、换层或降低边沿；
4. 只有噪声随这个因子同步变化，才把它归因给串扰。

“两根线间距够不够”没有脱离叠层、平行长度、边沿和回流的万能答案。

## 六、损耗、模式转换与 S 参数：一个看频段，一个看模式

导体趋肤效应、介质损耗、铜箔粗糙度、过孔和连接器会让高频更难通过，于是脉冲拖尾、产生 ISI。S21 用来描述端口之间的传输，S11 描述输入端反射；对差分通道还应转换为 mixed-mode S 参数。

![图7：同一教学通道的两个视角。左边是 S21/S11 的频率视角，右边是 TDR 阻抗剖面。S 参数回答“哪个频段传不过/反得多”，TDR 回答“空间上哪里不连续”；两者互补。曲线是教学物理模型，不是规范限值。](/images/ss01/ill07_simap.png)

![图8：mixed-mode S 参数。Sdd 表示差模到差模，Scc 表示共模到共模；Sdc/Scd 是模式转换。模式转换通常指向几何、回流或连接器不对称，具体限值必须回到接口规范及其端口定义。](/images/ss01/ill08_simap.png)

### VNA、去嵌、因果和无源：数字好看不等于模型可信

VNA 量到的默认是“仪器端口到仪器端口”，夹具、线缆和探头都在里面。校准是把已知仪器误差移到一个校准平面；去嵌则用夹具模型把参考面进一步移动到 DUT 边界。两者都不是点一下软件就能当真。

![图9：夹具与参考面。去嵌必须依赖已验证的夹具模型；若模型不准，可能放大噪声并产生非因果、非无源的网络。检查校准件残差、时域门控和适用的因果性/无源性/互易性。](/images/ss01/ill09_simap.png)

本段的规范性方法来源应查 **IEEE Std 370-2020《Electrical Characterization of Printed Circuit Board and Related Interconnects at Frequencies up to 50 GHz》**，并按仪器/夹具厂商校准套件说明执行。本文不自造 S 参数合格线。

## 七、眼图：它是压缩后的结果页，不能唯一归因

眼图把很多 UI 的波形按单位间隔折叠在一起。眼高代表电压方向的可用余量，眼宽代表时间方向的可用余量；掩模、参考接收器、CDR、滤波、码型、采样数和 BER 目标一起决定“这只眼到底是什么意思”。

![图10：两种不同根因可以得到相似的小眼。损耗/ISI 与反射/不连续都可能压缩开口；串扰、噪声、抖动、摆幅和测量带宽也会参与。眼图不能单独给出唯一根因。](/images/ss01/ill10_simap.png)

下面的动画只改变同一教学模型中的通道损伤；眼高/眼宽读数直接来自动画烘焙的真实密度图。红色掩模是**教学判据**，不是任何协议模板。

![图11动图：贯穿教学模型的损耗/ISI 扫描。通道损伤连续增加，真实生成的眼图与读数同步变化；红色掩模仅用于说明余量如何被吃掉。](/images/ss01/anim01_loss.gif)

正确说法是“这张眼图与某些根因一致”，再用 TDR、VNA、近端时域波形、换线/换夹具、改变码型等证据去排除其它解释。尤其不要把“眼图过了”误写成“通道每个机制都正确”。

## 八、抖动：先定义 TIE，再谈 RJ、DJ、CDR 与 BER

TIE（Time Interval Error）是实际边沿相对某个**明确参考时钟**的时间误差。参考时钟不是装饰：不同的恢复时钟、PLL 带宽或 SSC 处理会改变哪些低频变化被跟踪、哪些变化留在 TIE 中。

常见分解里：

- RJ（随机抖动）常用高斯近似描述，理论尾部无界；
- DJ（确定性抖动）是有界的统称，可包含 ISI、周期性干扰、占空比失真等；
- dual-Dirac 是用两个狄拉克峰再卷积高斯来拟合直方图的一种工程模型，用于从有限样本外推 BER。

![图12：TIE 与 dual-Dirac 教学图。双峰反映确定性成分，峰宽反映随机成分；能否外推到某 BER 取决于模型、样本量、码型、参考时钟与测量设置，不能把一次截图当成无限可靠的尾部统计。](/images/ss01/ill11_simap.png)

![图13动图：同一教学链路连续增加 DJ/RJ 后，TIE 分布加宽的后果投影到眼图时间方向。真实 CDR 对低频抖动会有跟踪作用；本动画用于说明“残余时间余量”而非替代任一规范的 jitter tolerance 曲线。](/images/ss01/anim03_jitter.gif)

因此，“总抖动多少 ps”至少还缺四个问题：在哪个 BER、哪种参考接收器、哪个频段/滤波、怎样分离。接收端测试还必须把 CDR 传递特性放进问题：低频相位漂移可能被 CDR 跟住，高频成分则更可能留在采样误差里。

## 九、均衡：FFE、CTLE、DFE 各救一部分，也各付一部分代价

有损信道像低通，快跳变比慢变化更容易被压平，于是出现 ISI。均衡不是“放大信号”，而是在发端、线性收端和判决反馈三个位置重新分配频谱/游标：

| 手段 | 放在哪里 | 擅长什么 | 主要代价 |
|---|---|---|---|
| FFE / 预加重 / 去加重 | 发射端 | 预先提高转变相关的高频成分 | 摆幅、功耗、EMI、合法档位限制 |
| CTLE | 接收端线性前端 | 提升高频，补一段平滑低通损耗 | 噪声也被提升，过度会更差 |
| DFE | 接收端判决后 | 用已判决符号扣除后游标 ISI | 错误传播、收敛、功耗和实现复杂度 |

![图14：三种均衡的分工与代价。均衡前先确认通道和参考接收器模型；均衡后仍要在规范允许档位中用 BER、眼余量和互通复验，不能拿任意“最开眼”的档位直接宣布成功。](/images/ss01/ill12_simap.png)

![图15动图：CTLE 提升扫描。真实教学波形先经过有损通道，再扫描有限的 CTLE 高频提升；眼图和读数随档位变化。提升过多会把噪声一起带起，因此没有“越大越好”的规律。](/images/ss01/anim04_eq.gif)

反射是特定延迟的回波，模式转换是差模到共模的能量泄漏；它们不一定能被 CTLE 消掉。先修几何、端接、回流或连接器，通常比把 EQ 旋钮拧到底更可靠。

## 十、NRZ 与 PAM4：速率相同不代表余量相同

NRZ 每个符号两个电平，承载 1 bit；PAM4 每个符号四个电平，承载 2 bit。PAM4 在相同波特率下能传更多 bit，但把垂直开口分成三只更小的眼，对线性度、噪声、抖动、接收机 DSP 和校准提出更高要求。

![图16：NRZ 与 PAM4 的电平对比。PAM4 不是“更快的 NRZ”，而是在相同波特率下以更小电平间距换取每符号更多 bit；任何余量比较都必须明确调制方式、波特率、参考接收器和 BER。](/images/ss01/ill13_simap.png)

这也解释了为什么不能只拿“Gb/s”对比测试难度：应同时问线速、波特率、编码、调制、通道损耗、FEC/BER 定义，以及规范要求的参考接收器。

## 十一、把余量做成 SI 预算：先分账，再谈总账

SI 预算不是把所有“ps”或所有“mV”随意相加。一个可执行的预算至少分三层：

1. **通道账**：阻抗/回损、插损、串扰、模式转换、反射位置；
2. **发收端账**：摆幅、上升时间、时钟/PLL、FFE/CTLE/DFE 合法档位、封装；
3. **观测与判决账**：夹具、参考面、探头/带宽、CDR、掩模或 BER 目标。

例如，电压方向可以列“发射摆幅 → 通道衰减 → 反射/串扰/噪声 → 判决门限余量”；时间方向可以列“UI → ISI → 残余抖动 → skew/采样误差 → CDR 后余量”。是否可直接 RSS、是否需要最坏情况相加，必须由统计独立性和对应规范定义决定。

表中的示例数字、动画红线和本篇示范掩模均为**教学示例/教学判据**。接口合规预算只能使用该接口版本的公开规范、测试夹具文档和参考接收器定义；本文不提供或替代任何私有一致性模板。

## 十二、一套可执行的诊断流程：把“猜根因”变成闭环

![图17：SI 诊断闭环。复现→时域观察→TDR 定位→VNA 频段/模式分析→一次只改一个因子→眼图、BER、互通和 EMI 复验。每一步都记录测试点、夹具、校准、参考面、带宽、码型和判据来源。](/images/ss01/ill14_simap.png)

下面这套流程可以直接放进问题单：

1. **复现并冻结条件**：速率、码型、供电、温度、板版本、线缆、插拔状态、软件版本；先确定问题可重复。
2. **先验证测量链**：探头带宽/接地、VNA 校准、夹具版本、端口映射、去嵌模型和参考面；换一条已知好的路径做 sanity check。
3. **时域看现象**：在驱动端、关键不连续点和接收端看边沿、过冲、回波、NEXT/FEXT、TIE、眼图。示波器不是定位工具的全部。
4. **TDR 找位置**：用阶跃与回波时间找阻抗台阶、过孔/连接器/参考面问题；要记住空间分辨率受阶跃上升时间限制。
5. **VNA 找频段和模式**：看 S11/S21，并对差分通道看 Sdd/Sdc 等；确认校准/去嵌后结果仍满足物理约束。
6. **一次只改一个可证伪因子**：例如补回流过孔、改端接、去掉 stub、换连接器、缩短平行段或调整合法 EQ 档位。不要一次改五件事。
7. **用最终判据复验**：发送端眼/掩模、接收端 BER 或 jitter tolerance、业务互通、温度边界和 EMI。修了截图不等于修了产品。

## 写在最后

板级 SI 的核心不是把每条线都做成“完美 50 Ω”，也不是让一张眼图看起来最漂亮。它是一个闭环：

> **先给链路和参考面定边界；用 RLCG、回流和几何理解传播；用边沿判断电气长度；用 Γ 和端接管理反射；用 NEXT/FEXT 管耦合；用 TDR 与 S 参数分别定位位置和频段；把眼图当结果页、把 TIE/CDR 放进抖动定义；最后在合法 EQ 和真实 BER/互通判据下复验。**

这样，SI 才从“看波形猜原因”，变成可以交接、可以复现、可以收敛的工程方法。

## 🔧 工程师速查（完整附录）

### A. 一页因果地图

| 看到什么 | 先怀疑什么 | 下一件工具/动作 | 不要直接下的结论 |
|---|---|---|---|
| 接收端过冲、固定延迟回波 | 阻抗台阶、stub、端接、回流变化 | TDR + 端接 A/B | “一定是芯片驱动太强” |
| Victim 跟随 Aggressor 翻转 | 平行耦合、回流缝隙、边沿过快 | 双通道时域、改变并行/回流 | “间距某个固定倍数就一定够” |
| S21 高频下滑 | 导体/介质损耗、连接器、长度 | VNA、材料/通道模型 | “只要 CTLE 更大就能救” |
| Sdc/Scd 变大、EMI 异常 | 差分不对称、P/N 过孔、参考面 | mixed-mode S 参数、结构检查 | “差分对等长就没有共模” |
| 眼图变小 | 损耗、反射、串扰、噪声、抖动、测量链 | TDR/VNA/波形 A/B | “小眼唯一等于损耗” |
| BER 高但平均眼还行 | 尾部抖动、CDR、偶发串扰/电源噪声 | TIE、浴盆/BER、频谱、长时采集 | “单张眼图能代表全部 BER” |

### B. 公式、假设与单位

| 项 | Unicode 公式 | 使用边界 |
|---|---|---|
| 低损耗特性阻抗 | Z0≈√(L/C) | L、C 为单位长度值；均匀单模传输线近似 |
| 传播速度 | v≈1/√(L·C) | 实际介质色散/粗糙度/结构需仿真或测量 |
| 电压反射系数 | ΓV＝(ZL−Z0)/(ZL+Z0) | 明确 Z0、端口和频率；复阻抗时 Γ 为复数 |
| 反射功率比 | |ΓV|² | 与电压反射系数不同；不保留正负号 |
| 边沿带宽近似 | f≈0.35/tr | 高斯近似的 10%～90% 上升时间关系，不是合规带宽 |
| 电长筛查 | tpd 单程约 ≥ tr/6 | 工程启发式；临界项目应仿真/测量 |
| 差分阻抗 | Zdiff≈2·Zodd | 耦合结构近似；以场求解/实测为准 |

### C. 模式与 S 参数速记

| 量 | 意义 | 常用来回答 |
|---|---|---|
| S11 / S22 | 端口反射 | 哪端匹配不好、回损在哪个频段恶化 |
| S21 / S12 | 正向/反向传输 | 插损、带宽、通道是否高频吃得太多 |
| Sdd21 | 差模到差模 | 差分信号真正传过去多少 |
| Scc21 | 共模到共模 | 共模通道的传输 |
| Sdc / Scd | 差/共模转换 | 不对称、回流或连接器导致的模式转换 |

**去嵌检查清单**：写清校准方法、校准平面、夹具版本/方向、端口配对、频率范围、插值/外推规则；检查已知直通件、残差、时域响应，并按适用条件检查无源性、因果性和互易性。方法参考：IEEE Std 370-2020。

### D. 仪器与仿真的边界

| 手段 | 最擅长 | 常见误用 |
|---|---|---|
| Scope | 时域边沿、过冲、串扰相关性、眼图、TIE | 长地线/不当带宽把测量伪影当 DUT；把单次眼图当根因 |
| TDR | 阻抗剖面、不连续位置、回波时间 | 忽略阶跃上升时间造成的空间分辨率；把夹具也算进 DUT |
| VNA | S 参数、插损/回损频段、mixed-mode | 未校准或错误去嵌；不写端口与参考面 |
| BERT | 接收端 BER、压力眼、jitter tolerance | 码型、误码计数时间、CDR/预置不匹配真实规范 |
| 2D/3D 场求解 | 几何、叠层、过孔/连接器电磁趋势 | 把未校准材料参数和简化边界当最终真值 |
| 系统仿真 | 通道、IBIS/AMI、EQ 扫描与预算 | 模型版本、封装/连接器/夹具缺失；仿真通过就跳过实测 |

### E. 端接与回流速查

| 场景 | 优先思路 | 必查副作用 |
|---|---|---|
| 点对点单负载 | 源端串阻与 Rout 合起来接近 Z0 | 边沿变慢、驱动能力、阻值位置必须贴近源端 |
| 多负载/长总线 | 拓扑约束 + 末端并联/戴维南/AC 端接 | 静态功耗、偏置、每个支路反射 |
| 差分对 | 确认 Zdiff 的末端端接及共模策略 | P/N 对称、模式转换、端接位置 |
| 跨参考面 | 给高频回流提供连续路径 | 回流过孔/平面耦合、不要让回流绕槽 |

### F. 眼图、抖动、均衡与调制

| 主题 | 必须写清的条件 | 核心提醒 |
|---|---|---|
| 眼图 | 码型、采样数、带宽、参考接收器、CDR、掩模版本 | 眼图是结果页，不能唯一归因 |
| TIE / 抖动 | 参考时钟、滤波、频段、BER、分离模型、观测长度 | dual-Dirac 是模型；RJ 尾部外推不是免费真相 |
| CDR | 环路/参考接收器定义、SSC 处理 | 低频抖动可能被跟踪，高频残余更伤采样 |
| FFE | 合法预置、摆幅、发送端限制 | 先整形再进信道 |
| CTLE | 提升档位、噪声、参考接收器 | 高频和噪声一起抬，不是越大越好 |
| DFE | 抽头、训练、错误传播、功耗 | 擅长后游标，不等于能修复所有物理缺陷 |
| NRZ/PAM4 | 线速、波特率、调制、BER/FEC、接收机 | PAM4 每符号 2 bit，但每只眼的电平余量更小 |

### G. SI 预算模板

| 预算层 | 要填什么 | 来源 |
|---|---|---|
| 通道 | Z0、公差、S11/S21、NEXT/FEXT、Sdc/Scd、长度、连接器 | 叠层/场求解、TDR、VNA、夹具模型 |
| 发收端 | 摆幅、tr、Rout、封装、FFE/CTLE/DFE、CDR | 芯片 datasheet、IBIS/AMI、接口规范 |
| 判决 | 掩模、BER、参考接收器、带宽、码型、温度 | 对应接口版本规范和测试程序 |
| 风险与验证 | 最坏组合、A/B、样本量、互通、EMI | 项目测试计划与问题单 |

### H. 可复制的 7 步诊断工单

1. **问题和复现条件**：板号/版本、接口档位、码型、温度、供电、线缆、软件。
2. **测量配置**：仪器、探头/夹具、带宽、校准、去嵌、端口、参考面、截图/原始数据路径。
3. **现象量化**：眼/掩模/BER/TIE/过冲/S 参数哪一项失败，判据来自哪里。
4. **位置证据**：TDR 的时间与推定物理位置，实物结构/过孔/连接器对照。
5. **频段与模式证据**：S11/S21/Sdd/Sdc 的异常频段，校准与无源/因果检查。
6. **单因子修正**：一次只改一项，写下预测结果和真实结果。
7. **闭环复验**：最终规范判据、长时 BER、真实业务、温度边界、互通与 EMI 是否都回归。
